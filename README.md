# ThesisEvosuite

Thesis-era exploration of automated test generation and analysis with EvoSuite for Java tutorial projects.

## Overview

This repository preserves the materials used to explore EvoSuite, an automated unit-test generation tool for Java. It includes Java tutorial projects, Maven examples, generated test artifacts, reports, analysis scripts, and supporting tutorial documents from the academic work.

## Why EvoSuite

The project examines automated test generation as a way to study test suites, coverage-oriented tooling, and the practical workflow of applying research software to Java codebases.

## Repository structure

```text
Tutorial_Experiments/  Java examples, generated EvoSuite tests, reports, and analyses
Tutorial_Maven/        Maven-oriented Java tutorial project
Tutorial_Stack/        Additional Java tutorial project
evosuite-master/       Preserved EvoSuite source and related materials
```

## Technologies and methods

- Java and Maven
- EvoSuite automated test generation
- Generated test suites and scaffolding
- Analysis scripts in R and Python
- Coverage and test-generation reports

## Scope

This is a preserved academic project rather than a maintained library. Generated outputs and historical build artifacts remain so the original workflow can be inspected. The repository does not claim a general conclusion beyond the materials it contains.
